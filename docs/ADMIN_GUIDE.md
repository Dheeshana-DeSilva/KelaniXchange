# Admin Guide

Admin users can manage platform activity from the admin panel.

## Access

1. Log in with an account that has the `ADMIN` role.
2. Open the admin area from the navigation.

## Dashboard

Use the dashboard to review overall platform metrics such as users, listings, reports, orders, and activity.

## Manage Users

Admins can:

- View all users.
- Add a user.
- Suspend or unsuspend a user.
- Update user role.
- Update user status.
- Delete a user.

Use suspension for temporary restrictions and deletion only when the account should be removed.

## Manage Listings

Admins can:

- View all marketplace listings.
- Edit listing information.
- Remove or hide inappropriate listings.
- Delete listings when needed.

## Manage Reports

Admins can:

- View reports submitted by users.
- Review listing/report details.
- Update report status to show progress or resolution.

## Manage Lost And Found

Admins can:

- View all lost and found posts.
- Update post status.
- Delete inappropriate or duplicate posts.

## Manage Notifications

Admins can:

- Create notifications for users.
- View existing admin-created notifications.
- Delete notifications.

## Manage Reviews

Admins can:

- View user reviews.
- Delete reviews that are abusive, irrelevant, or violate platform rules.

## Good Admin Practice

- Avoid deleting data unless moderation requires it.
- Prefer status changes when a reversible action is enough.
- Keep notification messages short and clear.
- Review reports before taking action against a listing or user.
