# User Guide

This guide explains the main actions for normal KelaniXchange users.

## Register And Login

1. Open the app.
2. Create an account with name, email, password, and contact details.
3. Log in to access marketplace actions such as posting, ordering, chat, wishlist, and reports.

## Browse Listings

1. Go to Marketplace.
2. Search or filter listings by category, condition, price, and location.
3. Open a listing to view photos, seller details, exchange availability, and actions.

## Create A Listing

1. Go to the listing creation page.
2. Enter title, category, price, quantity, condition, location, and description.
3. Upload up to 5 images.
4. Enable exchange availability if other students can offer items instead of paying cash.
5. Publish the listing.

## Buy An Item

1. Open a listing.
2. Choose quantity and checkout details.
3. Select a payment method.
4. Add payment reference or upload proof when required.
5. Track the order from My Orders.

## Manage Sales

1. Open My Sales.
2. Review incoming orders.
3. Update order status when processing, shipping, delivering, or cancelling.

## Request An Exchange

1. Open a listing that allows exchanges.
2. Choose one of your listings as the offered item.
3. Send the exchange request.
4. Track sent and received exchanges from My Exchanges.

## Use Chat

1. Start chat from a listing or user profile.
2. Send messages to coordinate item details, pickup location, or exchange details.
3. Read notifications for new message activity.

## Lost And Found

1. Open Lost & Found.
2. Browse lost or found posts.
3. Create a post with type, title, category, date, location, description, and optional photo.
4. Mark your post as resolved when the item is returned or found.

## Wishlist

1. Add listings to the wishlist from marketplace pages.
2. Open Wishlist to view saved listings.
3. Remove items that are no longer needed.

## Reports And Reviews

- Report suspicious or inappropriate listings from the listing/report flow.
- Leave reviews after successful orders or exchanges when the app allows it.
